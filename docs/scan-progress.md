- **Gotcha for future scans:** when a word is reused across many units, the field content shown on its Reference card comes from whichever unit file has the highest `type` rank *and*, among ties, whichever is earliest in the `mergeWordsAcrossUnits([...])` array in `src/data/reference.ts` (Level 1 files are listed before Level 2-5, so a Level 1 unit's own copy of a word can silently win over a Level 4 unit's copy of the "same" word even though the Level 4 file looks newer/richer). If a merged word's displayed meaning looks wrong or too narrow for the new unit's sense, don't assume the file you just edited is the one users see — grep every `content/subjects/english/courses/**/vocabulary.json` for that `"id": "global_<word>"` first, and edit the one that actually wins.
