# Design notes — Unit 3 Grammar 2 — Comparatives with more + adjective (`ow-l4-u3-grammar-2.html`)

## The lesson

- Our World Level 4, Unit 3 *Long Ago and Today* · SB p. 47 · TR 3.6 · LP pp. 112–113 · WB p. 31 · GWB pp. 12–13 · cutouts SB p. 173
- Objective (LP p. 112, verbatim): compare things using more + an adjective
- Target pattern: **A is more + adjective + than B** for adjectives of three or more syllables and two-syllable words like *modern*; *than* dropped when the comparison is clear (Life was more difficult back then); *one* for the second noun
- Academic Language: syllable · recycled: Vocabulary 2 (modern, difficult, expensive, old-fashioned, important) · Unit 1 -er comparatives
- **Hard scope line:** more … than only. No superlatives (most), no less, no as … as.

## The spine — The Comparison Race

The SB p. 173 game board *is* the spine. Each right comparison moves Leo one space; the spaces go up on the race wall that every spine slide shows. The board itself is shown square by square as the book prints it — Start (an old dial telephone and a cell phone), the TVs, washing by hand and a washing machine, “There is no electricity. Go back two spaces.”, the houses, the bikes, “You have to wash clothes by hand. Go back one space.”, a video game and checkers, End (the cars) — and the payoff is the real board game with Dad: heads move 1, tails move 2.

## The two bars

*Detailed*: every comparative is built in presses — clap the syllables, add *more*, add *than* — so *difficulter* never looks possible; the -er/more choice is a sort Leo makes by counting. The four common errors (-er on a long word, *more* after the adjective, *that* for *than*, *more* + -er together) are shown broken first. *Creative*: the book’s own game board becomes the race, so the payoff is a real game, not a worksheet.
