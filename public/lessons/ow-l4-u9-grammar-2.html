🇯🇵 The big L1 difference
  • Japanese puts the description before the noun; English puts it after. This is the single hardest thing about this grammar for Leo.
  • Read the Japanese order out loud, then the English, and let him hear the flip.
  • Also: Japanese has no word like which at all — nothing to translate, so he must learn the slot.
🇯🇵 Japanese ↔ English

The description flips sides 🔄

JAPANESE ORDER

あなたを地球(ちきゅう)に引(ひ)っぱる 力(ちから)

description ➡️ then the thing

ENGLISH ORDER

a force which pulls you toward Earth

the thing ➡️ then the description

🎯 Say the thing first. Then which. Then everything else. Japanese has no word for which — so listen for the slot, don't translate it.

Practice · Fix the sentence 🔧

What is wrong here?

🚫 A swing is a seat which it hangs from two ropes.

✅ A swing is a seat which hangs from two ropes.
"which" already means the seat — don't say it twice.

🚫 A skater is a person which skates.

✅ A skater is a person who skates.
People take "who". Things take "which".

🚫 Gravity which is a force pulls you down.

✅ Gravity is a force which pulls you down.
"which" comes right after the thing it explains.
