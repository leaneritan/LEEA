⏱️ Rule 2 — present in BOTH halves

✅ SAY THIS

If it snows, school closes early.

I put on my coat if the weather is cold.

❌ NOT THIS

If it will snow, school closes early.

If it snows, school is going to close.

📌 It’s a fact — true every time. So both verbs are simple present. No will, no going to, no past.

🔄 Rule 4 — flip it! The comma rule

IF FIRST → comma

If it snows, school closes early.

🔄
IF SECOND → no comma

School closes early if it snows.

📌 Same meaning both ways. Only the comma changes: If at the start = comma in the middle.

🇯🇵 Corner 1 — you already have it: 〜と to

日本語 nihongo

雨が降(ふ)ると、傘(かさ)をさします。
Ame ga furu to, kasa o sashimasu.

春になると、桜(さくら)が咲(さ)きます。
Haru ni naru to, sakura ga sakimasu.

English

If it rains, I use an umbrella.

If it’s spring, cherry blossoms bloom.

🎉 Good news: Japanese 〜と to is for things that happen every time — exactly like today’s English. And both use the plain present verb: 降る furu = rains. No future needed!

🇯🇵 Corner 2 — the little word jumps to the front

日本語 — at the END

雪が降ると、
Yuki ga furu to,

と to comes after the verb. And the condition is always first.

English — at the START

If it snows,

If comes before the subject. And English can flip the halves!

❌
It snows if, school closes.
🔄
Flip it — where does if go now?

🇯🇵 Corner 3 — the subjects Japanese leaves out

Japanese often has no subject at all. English needs one in each half — even a tiny it for the weather.

🌧️
雨が降ると、家にいます。
Ame ga furu to, ie ni imasu.
🌙
暗くなると、電気をつけます。
Kuraku naru to, denki o tsukemasu.
🥵☀️
暑いと、水をたくさん飲みます。
Atsui to, mizu o takusan nomimasu.
🧍❄️
吹雪(ふぶき)だと、学校が休みです。
Fubuki da to, gakkō ga yasumi desu.
