Cause and effect with simple past and modals

Use so that + could or would to give the reason someone did something in the past.

過去に何かをした理由を言うときは so that + could / would を使います。

simple past clause + so that + subject + could / would + base verb

…so that + subject + could + base verb

Expected result

…so that + subject + would + base verb

Negative result

…so that + subject + wouldn't + base verb

We wore life jackets so that no one would have an accident.

事故が起きないように救命胴衣を着けました。

Taking it somewhere

…so that + subject + could + take / drink / buy

Some were buried with chocolate so that they could take it with them.

持って行けるように、チョコレートとともに埋葬された人もいました。

Short form

so that → so (in speech)

He showed me how to climb rocks, so that I can get stronger.

強くなれるように、彼は岩の登り方を教えてくれました。

Use could for what someone was able to do

  • He printed the recipe / read it → He printed the recipe so that he could read it.
  • The Spanish took the seeds / drink chocolate in Spain → The Spanish took the seeds so that they could drink chocolate in Spain.
Our World Level 6 · Unit 3 · Student Book audio script
do

Use would for the expected result

  • We put them on the table / it be easy to find them → We put them on the table so that it would be easy to find them.
  • The Aztecs added spices / it taste better → The Aztecs added spices so that it would taste better.

do

Make the purpose negative with wouldn't

  • She heated the milk slowly / it not burn → She heated the milk slowly so that it wouldn't burn.
  • We wore life jackets / no one have an accident → We wore life jackets so that no one would have an accident.
