Present perfect progressive with for and since

Use have or has + been + verb-ing to talk about an action that started in the past and is still going on now. Use for with a length of time and since with the moment it started.

過去に始まって今も続いている動作は have / has + been + 動詞の -ing 形 で表します。期間の長さには for、始まった時点には since を使います。

subject + have / has + been + verb-ing + for / since + time

Been never changes

  • I / take swimming lessons / three months → I've been taking swimming lessons for three months.
  • My sister / take lessons / March → My sister has been taking lessons since March.
