Order of adjectives

When you use more than one adjective before a noun, put them in a fixed order: opinion, size, age, shape, colour, origin, then material.

名詞の前に形容詞を2つ以上置くときは、意見 → 大きさ → 新旧 → 形 → 色 → 出身 → 素材 の順に並べます。

opinion + size + age + shape + colour + origin + noun
