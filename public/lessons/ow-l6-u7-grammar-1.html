Passive with modals

Use a modal — must, must not, have to, can, can't — plus be plus the past participle to say what has to or can be done to something.

must・must not・have to・can・can't などの助動詞 + be + 過去分詞 で、何がされなければならないか、何ができるかを表します。

subject + modal + be + past participle

must be + past participle for rules

  • headlamps / wear / in dark caves → Headlamps must be worn in dark caves.
  • safety gear / use / to stay safe → Safety gear must be used to stay safe.

must not = forbidden, can't = impossible

  • dangerous places / enter / alone → Dangerous places must not be entered alone.
  • new species / analyze / underwater → New species can't be analyzed underwater.

can be + past participle for what is possible

  • a rope / use / to help us descend → A rope can be used to help us descend.
  • stalactites / see / in this cave → Stalactites can be seen in this cave.
